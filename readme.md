# 🌿 Cartão de Visitas Digital • Módulo I

> Um projeto desenvolvido com HTML5, CSS3 e JavaScript puro, criado como parte da jornada de estudos em Front-end.

<div align="center">
  <p>✨ <em>Um cantinho digital para centralizar links e conexões profissionais.</em> ✨</p>
</div>

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído do zero, sem o uso de frameworks pesados, aplicando os fundamentos essenciais da web:

* **HTML5:** Estrutura semântica e acessível da página.
* **CSS3:** Estilização com paleta de cores acolhedora (tons pastéis), fontes customizadas (*Quicksand*).
* **JavaScript (Vanilla):** Lógica interativa para geração dinâmica de partículas flutuantes no fundo da página.

---

## ✨ Funcionalidades

* ☕ **Design Cozy & Minimalista:** Interface limpa focada em conforto visual e tipografia suave.
* 👾 **Suporte a Pixel Art:** Tratamento especial via CSS para manter avatares em pixel art nítidos e sem borrões.
* 🌸 **Fundo Dinâmico com Partículas:** Script em JavaScript que gera um efeito atmosférico flutuante de forma procedural.
* 📱 **Responsividade:** Layout adaptado para diferentes tamanhos de tela.
